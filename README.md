# SLF4J-RS
Unofficial Rust port of [SLF4J](https://www.slf4j.org/).
[Original Repository](https://github.com/qos-ch/slf4j.git)

This proyect is an independient, unofficial port of SLF4J version 2.0.17, originally developed in Java.

This proyect is not affileated with or endorsed by the original SLF4J maintainers
